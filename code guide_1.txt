Of course. This is an excellent and very practical upgrade for your application. Moving from a "wipe and replace" model to a versioned, file-based system makes your tool much more powerful and safe to use.

### The New Architecture: File-Based Configuration Management

The methodology we will use is simple and robust. Instead of having one single `track_layout.db` that gets overwritten, we will treat each saved configuration as its own separate SQLite database file.

1.  **Dedicated Folder:** We will create a new folder named `configs` inside your server directory. Every time you save, a new `.db` file will be created here (e.g., `MyLayout_v1.db`, `Test_Config_April.db`).
2.  **New Backend Role:** Your server.js will be upgraded to act as a file manager. It will no longer work with just one database; instead, it will be ableto:
    *   List all available configuration files from the `configs` folder.
    *   Create a brand new database file with the full schema and data when you save.
    *   Read data from any specific database file you choose to load.
3.  **New Frontend Role:** Your React app's UI will be updated to support this new workflow.
    *   The "Save" button will now ask you for a filename.
    *   The "Load" button will first ask you which of the previously saved files you want to open.

This architecture is powerful because each file is a complete, self-contained snapshot. You can easily back them up, share them, or revert to an older version without any risk.

// server/server.js

const express = require("express");
const Database = require("better-sqlite3");
const cors = require("cors");
const path = require("path");
const fs = require("fs"); // Node.js File System module, needed for file operations

const app = express();
const PORT = 5000;

// Middleware
app.use(cors());
app.use(express.json({ limit: "50mb" })); // Increase payload size limit for large configs

// --- NEW: Directory to store all configuration database files ---
const configsDir = path.join(__dirname, "configs");
// Ensure the 'configs' directory exists
if (!fs.existsSync(configsDir)) {
  fs.mkdirSync(configsDir, { recursive: true });
}

// --- NEW: Function to create the database schema in a new file ---
// This function will be called every time we save a new configuration.
const createSchema = (dbInstance) => {
  dbInstance.exec(`
    CREATE TABLE IF NOT EXISTS stations (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      name TEXT NOT NULL,
      station_id TEXT NOT NULL UNIQUE,
      abs REAL NOT NULL
    );
    CREATE TABLE IF NOT EXISTS tracks (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      tin_id TEXT,
      focus_from REAL,
      focus_to REAL,
      selected_color TEXT,
      track_direction TEXT,
      track_position INTEGER,
      track_visual_traversal_direction TEXT
    );
    CREATE TABLE IF NOT EXISTS global_tags (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      selected_line TEXT,
      direction TEXT,
      tag_type TEXT,
      num_tags INTEGER,
      tag_start_abs REAL,
      tag_end_abs REAL,
      distance_between_tags_meters REAL,
      tag_id TEXT
    );
    CREATE TABLE IF NOT EXISTS tag_ranges (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      start TEXT,
      end TEXT
    );
    CREATE TABLE IF NOT EXISTS signals (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      signal_name TEXT,
      signal_abs REAL,
      signal_type TEXT,
      default_aspect TEXT,
      selected_line TEXT,
      direction TEXT
    );
    CREATE TABLE IF NOT EXISTS shunts (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      selected_line TEXT,
      shunt_name TEXT,
      shunt_abs REAL
    );
    CREATE TABLE IF NOT EXISTS bslbs (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      selected_line TEXT,
      direction TEXT,
      abs REAL
    );
    CREATE TABLE IF NOT EXISTS caution_boards (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      selected_line TEXT,

    );
    CREATE TABLE IF NOT EXISTS lc_gates (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      lc_number TEXT,
      lc_type TEXT,

      lc_class TEXT,
      abs REAL
    );
    CREATE TABLE IF NOT EXISTS points (
      id INTEGER PRIMARY KEY AUTOINCREMENT,

      abs REAL
    );
    CREATE TABLE IF NOT EXISTS track_sections (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      title TEXT,
      line TEXT,
      direction TEXT,
      start_abs REAL,
      end_abs REAL,
      track_section_name TEXT
    );
  `);
};

// --- API Endpoints ---

// NEW Endpoint: List all available configuration files
app.get("/api/list-configs", (req, res) => {
  try {
    const files = fs
      .readdirSync(configsDir)
      .filter((file) => file.endsWith(".db")) // Only show .db files
      .map((file) => file.replace(".db", "")); // Send names without the extension
    res.json({ success: true, files });
  } catch (error) {

    res

// NEW Endpoint: Save a new configuration to a specific file
app.post("/api/save-config-as", (req, res) => {
  const { filename, configData } = req.body;

  // Basic sanitization to prevent directory traversal attacks
  const safeFilename = path.basename(filename).replace(/[^a-z0-9_-]/gi, "_");
  if (!safeFilename) {
    return res
      .status(400)
      .json({ success: false, message: "Invalid filename provided." });
  }

  const dbPath = path.join(configsDir, `${safeFilename}.db`);
  const db = new Database(dbPath); // Create or open the specific database file

  try {
    // Step 1: Create the full schema in the new database file
    createSchema(db);

    // Step 2: Insert all the data within a transaction
    const {
      stationA,
      stationB,
      tracks,
      globalTagConfigs,
      tagRanges,
      signals,
      shunts,
      bslbs,
      cautionBoards,
      lcGates,
      points,
      trackSections,
    } = configData;

    db.transaction(() => {
      // Note: We don't need to DELETE anymore because this is a fresh file.
      const insertStationA = db.prepare(
        "INSERT INTO stations (name, station_id, abs) VALUES (?, ?, ?)"
      );
      insertStationA.run(stationA.name, stationA.id, parseFloat(stationA.abs));
      const insertStationB = db.prepare(
        "INSERT INTO stations (name, station_id, abs) VALUES (?, ?, ?)"
      );
      insertStationB.run(stationB.name, stationB.id, parseFloat(stationB.abs));

      const insertTrack = db.prepare(
        "INSERT INTO tracks (tin_id, focus_from, focus_to, selected_color, track_direction, track_position, track_visual_traversal_direction) VALUES (?, ?, ?, ?, ?, ?, ?)"
      );
      tracks.forEach((track) =>
        insertTrack.run(
          track.tinId,
          parseFloat(track.focusFrom),
          parseFloat(track.focusTo),
          track.selectedColor,
          track.trackDirection,
          track.trackPosition,
          track.trackVisualTraversalDirection
        )
      );

      const insertTag = db.prepare(
        "INSERT INTO global_tags (selected_line, direction, tag_type, num_tags, tag_start_abs, tag_end_abs, distance_between_tags_meters, tag_id) VALUES (?, ?, ?, ?, ?, ?, ?, ?)"
      );
      globalTagConfigs.forEach((tag) =>
        insertTag.run(
          tag.selectedLine,
          tag.direction,
          tag.tagType,
          parseInt(tag.numTags),
          parseFloat(tag.tagStartAbs),
          parseFloat(tag.tagEndAbs),
          parseFloat(tag.distanceBetweenTagsMeters),
          tag.tagId
        )
      );

      const insertTagRange = db.prepare(
        "INSERT INTO tag_ranges (start, end) VALUES (?, ?)"
      );
      (tagRanges || []).forEach((range) =>
        insertTagRange.run(range.start, range.end)
      );

      const insertSignal = db.prepare(
        "INSERT INTO signals (signal_name, signal_abs, signal_type, default_aspect, selected_line, direction) VALUES (?, ?, ?, ?, ?, ?)"
      );
      signals.forEach((signal) =>
        insertSignal.run(
          signal.signalName,
          parseFloat(signal.signalAbs),
          signal.signalType,
          signal.defaultAspect,
          signal.selectedLine,
          signal.direction
        )
      );

      const insertShunt = db.prepare(
        "INSERT INTO shunts (selected_line, shunt_name, shunt_abs) VALUES (?, ?, ?)"
      );
      shunts.forEach((shunt) =>
        insertShunt.run(
          shunt.selectedLine,
          shunt.shuntName,
          parseFloat(shunt.shuntAbs)
        )
      );

      const insertBslb = db.prepare(
        "INSERT INTO bslbs (selected_line, direction, abs) VALUES (?, ?, ?)"
      );
      bslbs.forEach((bslb) =>
        insertBslb.run(bslb.selectedLine, bslb.direction, parseFloat(bslb.abs))
      );

      const insertCautionBoard = db.prepare(
        "INSERT INTO caution_boards (selected_line, direction, abs) VALUES (?, ?, ?)"
      );
      cautionBoards.forEach((cb) =>
        insertCautionBoard.run(cb.selectedLine, cb.direction, parseFloat(cb.abs))
      );

      const insertLcGate = db.prepare(
        "INSERT INTO lc_gates (lc_number, lc_type, operation_type, lc_class, abs) VALUES (?, ?, ?, ?, ?)"
      );
      lcGates.forEach((lc) =>
        insertLcGate.run(
          lc.lcNumber,
          lc.lcType,
          lc.operationType,
          lc.lcClass,
          parseFloat(lc.abs)
        )
      );

      const insertTrackSection = db.prepare(
        "INSERT INTO track_sections (title, line, direction, start_abs, end_abs, track_section_name) VALUES (?, ?, ?, ?, ?, ?)"
      );
      trackSections.forEach((section) =>
        insertTrackSection.run(
          section.title,
          section.selectedLine,
          section.direction,
          parseFloat(section.startAbs),
          parseFloat(section.endAbs),
          section.trackSectionName
        )
      );

      const insertPoint = db.prepare(
        "INSERT INTO points (point_a, point_b, abs) VALUES (?, ?, ?)"
      );
      points.forEach((point) =>
        insertPoint.run(point.pointA, point.pointB, parseFloat(point.abs))
      );
    })(); // Execute the transaction

    res.json({
      success: true,
      message: `Configuration saved as ${safeFilename}.db`,
    });
  } catch (error) {
    console.error("Database save error:", error);
    res
      .status(500)
      .json({ success: false, message: `Failed to save configuration: ${error.message}` });
  } finally {
    if (db) db.close(); // Always close the database connection
  }
});

The backend is now ready. The next step is to update your React application. This involves changing the UI to ask for filenames. While providing the full React code for modals can be complex, here is a clear guide on the logic you need to implement.

1.  **Add New State Variables:**
    ```javascript
    const [configFiles, setConfigFiles] = useState([]);
    const [showLoadModal, setShowLoadModal] = useState(false);
    // You will also need state for a "Save As" modal/prompt.
    ```

2.  **Update "Save Configuration" Button:**
    *   Its `onClick` handler should now open a prompt or a modal that asks the user for a filename.
    *   You can use the simple browser `prompt()` for a quick implementation:
        ```javascript
        const handleSaveClick = async () => {
          const filename = prompt("Please enter a name for your configuration:");
          if (filename) {
            // Gather all your config data into one object
            const configData = { stationA, stationB, tracks, ... };
            
            await fetch("http://localhost:5000/api/save-config-as", {
              method: "POST",
              headers: { "Content-Type": "application/json" },
              body: JSON.stringify({ filename, configData }),
            });
            alert("Configuration saved!");
          }
        };
        ```

3.  **Update "Load Configuration" Button:**
    *   Its `onClick` handler should first fetch the list of available files.
    *   Then, it should show a modal or list to the user.
        ```javascript
        const handleLoadClick = async () => {
          const response = await fetch("http://localhost:5000/api/list-configs");
          const data = await response.json();
          if (data.success) {
            setConfigFiles(data.files);
            setShowLoadModal(true); // Show a modal with the list of files
          }
        };
        ```
    *   Your `loadConfiguration` function needs to accept a filename.
        ```javascript
        const loadConfiguration = async (filename) => {
          // The old logic is the same, just the URL changes

          // ... then process the data and set all your states
        };
        ```
    *   In your "Load" modal, when a user clicks on a filename, you would call `loadConfiguration(chosenFile)` and close the modal.

### Example of the New Workflow

Here is how you will use the upgraded application:

1.  **Start Fresh:** You open the application and design a new layout.
2.  **Save Your Work:** You click the "Save Configuration" button.
    *   A small window pops up asking for a name. You type `My_First_Layout` and click OK.
    *   The backend creates a new file: `server/configs/My_First_Layout.db`.
3.  **Make Changes:** You continue working and make some significant changes. You want to save this as a new version.
4.  **Save Again:** You click "Save Configuration" again.
    *   The prompt appears. This time, you type `My_First_Layout_v2`.
    *   The backend creates a second file: `server/configs/My_First_Layout_v2.db`. Your original file is untouched.
5.  **Load an Old Version:** The next day, you want to go back to your first version.
    *   You click the "Load Configuration" button.
    *   A list appears on your screen showing:
        *   `My_First_Layout`
        *   `My_First_Layout_v2`
    *   You click on `My_First_Layout`.
    *   The frontend calls the backend, which reads from `My_First_Layout.db` and sends the data back. Your React form instantly updates to show your original design.

This new architecture provides a much safer and more flexible way to manage your work.
